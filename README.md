# masks.bsns.ru

Статический репозиторий реальных масок BZN и автономная страница проверки библиотеки.

## Состав

- `NewUI/masks/*.webp` — оригинальные маски, загружаемые по FTP и исключённые из Git.
- `NewUI/masks/files.js` — автоматически создаваемый индекс найденных файлов, также передаваемый по FTP.
- `NewUI/masks/data/*.js` — автоматически создаваемые lazy-копии для `file://` и CORS-независимой загрузки, также передаваемые по FTP.
- `runtime-config.js` — единая точка адресов и размера страницы.
- `index.html` — автономная проверка через общий интерфейс `library-ui.bsns.ru`.

## Проверка

```text
node NewUI/tools/build-ready-mask-data.mjs
node tests/masks-contract.test.mjs
node tests/masks-browser.mjs
```

После генерации по FTP загружается целиком локальная папка `NewUI/masks/`. Скрипт, интерфейс и конфигурация обновляются через Git. Сайт полностью статический; PHP и база данных не требуются.

## Единая админка ресурсов

`resource-admin/` — тонкая исполняемая точка входа на PHP-домене. Она вызывает единый Resource Engine из соседнего репозитория `images.bsns.ru`; исходные картинки, каталог, эскизы и оптимизированные версии остаются в одном общем хранилище. Старый `upload.php` продолжает работать отдельно и не изменяется.

Маршрут к движку и адрес его статических файлов инкапсулированы в `BznResourceEngineGateway`. При смене ресурсного домена интерфейс и вызовы API менять не потребуется.
