# Правила репозитория masks.bsns.ru

- Репозиторий содержит только статические ресурсы библиотеки масок.
- Реальные маски хранятся в `NewUI/masks/`, индекс — в `NewUI/masks/files.js`.
- Lazy file-mode копии генерируются скриптом `NewUI/tools/build-ready-mask-data.mjs`.
- Количество элементов страницы и адреса внешнего интерфейса задаются только в `runtime-config.js`.
- Перед публикацией обязательны contract-тест и три чистых browser-цикла.
- Не добавлять PHP, секреты, токены и пользовательские файлы.
